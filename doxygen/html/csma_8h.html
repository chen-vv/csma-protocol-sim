◆ READY_TO_TRANSMIT

#define READY_TO_TRANSMIT   0

Macro to determine whether a node is ready to transmit.

This macro is used to check the node's backoff state. When the value of the backoff equals this macro, the node is ready to transmit its packet.

◆ TRANSMIT_COMPLETE

#define TRANSMIT_COMPLETE   0

Macro to determine whether a node has completed transmitting.

This macro is used to check whether a node's packet transmission is completed. When the value of the node's ticks_remaining equals this macro, the node has completed transmitting its packet.

◆ generate_backoff()

int generate_backoff ( int node_id,
int ticks,
int R )

node_id = ID of node ticks = number of elapsed for loop iterations R = the R value, aka backoff upper limit value, since backoff is in the range of [0, R) Returns the backoff value of the node, which is the pseudorandom number generator following backoff = mod(node_id + ticks, R)
